## S9: google's header image drawn below the search box

**Symptom (Trace #978, board 11-03):** on google's 2026-11-03 election-day doodle page the
doodle (`/logos/doodles/2026/us-midterm-elections-2026-copy-...-2x.png`) drew at 1000x400
under the buttons and over the footer, instead of 575x230 in the logo slot. It pushed
looks-right over the 15% bar (15.26%).

**Shape (from the Wayback copy of the page, 2026-11-04 01:09Z):**

```
.sI1XGe  grid, height 240 (calc(100% - 560px) clamped), one minmax(0,1fr) row,
         justify-items/align-items: center
  .eI7Peb  height:100%; max-height:230px; margin-top:auto; text-align:center   (grid item)
    <div style="height:calc(100% - 400px)">                                  (spacer)
    <a><picture><img width=1000 height=400
         style="max-height:100%; max-width:100%; width:auto; object-fit:contain"></picture></a>
```

Chromium 143/148: item 575 wide, spacer 0, image 575x230 at the item's top.

**Three missing percent bases, all fixed here:**

1. `layout_inline` laid its children out with no percent base, so an image inside `<a>` (or
   `<a><picture>`) treated `max-height: 100%` as `none`. An inline box is not a containing block
   (CSS 2.1 §10.1); its children now get the block container's base.
2. A non-stretched auto-width grid item is sized from its max-content width, which read the
   image's 1000px width attribute. `place_item_in_area` now hands the area's height to the
   measure (`PERCENT_HEIGHT_BASE`, a thread-local that is `None` for every other caller, the same
   pattern as `COMPRESSIBLE_REPLACED_MIN`); `own_max_content_width` passes a block's definite
   height to its children and an inline's base through, and measures an image with a base by
   `layout_image_in`, so `max-height: 100%` caps the transferred width.
3. Phase 9's inline-formatting arm flowed an item's children with `None`, so any percentage
   child of an item that also holds inline content read the viewport (a `height: 50%` block was
   400 in a 230px item). An item with a height of its own now hands it.
