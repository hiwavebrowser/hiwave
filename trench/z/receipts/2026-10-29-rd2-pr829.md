## RD2: a `::before`/`::after` with `display: none` generates no box

PLAN-z row RD2, found while reducing RD1 on 10-29. `Engine::pseudo_element_box` built a box for every pseudo-element whose style had `content`. With `display: none` the box fell through to the `Block` arm, and an absolutely positioned one painted. reddit's interstitial `main:before { ...; position: absolute; display: none }` drew its #d93900 disc over the logo. Chrome generates no box (CSS Display 3 §2.5).

### Fix
`pseudo_element_box` now returns `None` when the cascaded `display` is `none`. That covers in-flow, floated, absolute and fixed pseudos, and a later rule that turns one off.
